# Инструкции для LLM-агента (MCP Dashboard)

## Когда вызывать

Если пользователь просит **карту, хороплет или сравнение по субъектам РФ** (регионы, области, республики, города федерального значения) — сначала используйте этот MCP, инструмент **`create_russia_map`**, а не самописный HTML, Highcharts или отдельный фронтенд.

## Порядок действий

1. Получить справочник кодов: **`get_russia_region_codes`** или прочитать resource **`dashboard://mcp-dashboard/russia-region-codes`**.
2. Сопоставить названия из запроса/источника данных с полем `regionCode` (ISO 3166-2:RU, например `RU-KHM`). В справочнике есть `aliases` (например ХМАО → `RU-KHM`).
3. Вызвать **`create_russia_map`** с аргументом `data` в формате ниже.
4. В ответе использовать **изображение PNG** для показа в чате и при необходимости **dashboardUrl** для интерактива (пока сервер запущен).

## Минимальный формат `data`

```json
{
  "years": [
    {
      "year": 2023,
      "regions": [
        { "regionCode": "RU-MOW", "value": 10.5 },
        { "regionCode": "RU-SPE", "value": 20 }
      ]
    }
  ]
}
```

Несколько лет — несколько объектов в `years` (слайдер на дашборде).

## Типичные ошибки

- **Неизвестный `regionCode`** — сервер вернёт `unknownRegionCodes` и `possibleMatches`. Исправьте коды и повторите вызов.
- **Пустой `years`** — будет ошибка формата до вызова карты.

## Инструменты

| Имя | Назначение |
|-----|------------|
| `get_russia_region_codes` | JSON со всеми субъектами и алиасами |
| `create_russia_map` | Сборка дашборда + PNG |

Resource со справочником дублирует JSON из `get_russia_region_codes` для клиентов с поддержкой resources.
